# Zebby 2.9.0

Stronger local models, with memory that releases when you finish.

- Download Qwen3 14B, Qwen3 30B A3B or Qwen3 32B from Settings. Recommendations account for available system and GPU memory. Qwen3 14B is the starting option for a Mac with 32 GB of unified memory; the larger models target 48 GB or more.
- Allocate context for the full request and its response budget, using the downloaded model's own tokenizer. Oversized requests explain what needs to change instead of trimming the job description or resume.
- Release downloaded-model memory after 30 idle seconds, or immediately with **Release memory** in Settings. Cancellation, sleep and app exit also release the worker. Memory-pressure checks protect other running apps.
- Give local models task-appropriate output budgets and progress-aware timeouts. Ollama requests now include a 30-second keep-alive.
- Preserve the selected model and thinking setting, including when GPU startup falls back to the CPU.

Includes the Boards fixes from 2.8.1. Applications and Boards database formats are unchanged.

Downloads include Windows x64 and ARM64 installers, an Apple Silicon Mac DMG, and a Microsoft Store MSIX bundle. The MSIX bundle is for Partner Center submission.

For local performance testing, see the [Apple Silicon benchmark guide](https://github.com/desigrit/zebby-the-scout/blob/v2.9.0/docs/local-ai-benchmarks.md).
