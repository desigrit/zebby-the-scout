# Zebby 1.6.5

- Repaired Mac bundle signing after packaging.
- Added DMG integrity, copied-bundle signature and actual app launch checks on macOS Tahoe.

The Mac build uses an ad-hoc signature and is not notarized by Apple. First launch needs a one-time approval. See the [Mac installation steps](https://github.com/desigrit/zebby-the-scout/blob/main/docs/guide.md#mac-first-launch).

Your database, resumes, settings and downloaded models are preserved.
