# Zebby 2.7.0

- **Boards (Beta)** tracks new listings across saved career searches. Add role or department instructions, check one board or all of them, and mark discoveries as reviewed.
- Setup chooses one folder and name for your Applications database and its Boards companion. Existing beta Boards files can be adopted or imported with their history.
- Boards uses your selected local model, API key or Zebby credits. Credit history identifies paid Boards batches. After a top-up, retry an interrupted scan to reuse completed work.
