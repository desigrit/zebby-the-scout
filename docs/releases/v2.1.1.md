# Zebby 2.1.1

## Consistent Settings controls

Settings actions now share the same sizing, spacing, typography, and icon treatment. Save, Buy credits, downloads, wallet recovery, computer connections, and updates use primary, secondary, or destructive variants from one component. Folder and external links retain their navigation style.

## Application status chart

The 30-day activity chart stacks applications by their current status: Applied, Heard back, Interview scheduled, and Rejected. Changing a role's status updates the bar for its original applied date. Bar totals stay the same.

A status legend and day tooltips show the breakdown. Keyboard navigation still supports arrows, Home, and End. Escape dismisses a tooltip, and tooltip placement stays within the chart on narrow windows.

This release adds no database migration or payment-service configuration change. Paid checkout remains unavailable until the hosted service is configured and its URL is included in a desktop build.
