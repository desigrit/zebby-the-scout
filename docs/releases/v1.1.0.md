# PM Application Tracker 1.1.0

## Downloadable CPU models

In **Settings > Analysis**, choose **Built-in local, downloadable models**, then choose a **Local model**. Selecting it starts the download. Once it is ready, use it for Plan and application match analysis without an API key, Ollama setup, or GPU. Model files are downloaded separately to keep installers light.

- **SmolLM2 360M:** 271 MB, basic keyword coverage and short overview suggestions.
- **Qwen3 0.6B:** 639 MB, small model with the full analysis prompts.
- **Qwen3 4B:** 2.50 GB, medium model with the full analysis prompts.
- **Qwen3 8B:** 5.03 GB, largest built-in model with the full analysis prompts.

Only SmolLM2 uses the compact analysis profile. OpenAI and configured Ollama models, including Qwen, continue using their selected model and full analysis path. Providers do not switch automatically on failure. Local Qwen quality depends on model size; larger models require more memory and time on CPU.

## Download controls and deletion

Settings shows progress, size, memory guidance, Pause, Resume, Retry, and Ready states. Completed downloads are verified and reused through updates. Models live in this computer's local app data folder, outside your shared SQLite file.

Each downloaded model has a **Delete** button and native **Cancel / Delete model** confirmation. On Mac, delete the models here before removing the app. On Windows, uninstalling removes known model download files, while updates retain them. Databases, backups, resumes, and Ollama models are preserved.

## Data and compatibility

This release uses the existing database format. Install it on each computer where you want the new local provider. Your plans and applications continue to share the same selected database; model downloads and provider settings stay local to each computer.

Download the direct `.exe` or `.dmg` installer for Windows x64, Windows ARM64, or Apple Silicon macOS below.
