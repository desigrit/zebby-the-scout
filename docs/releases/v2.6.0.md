# Zebby 2.6.0

- Create tailored resumes from an analyzed Plan, using the selected model and thinking level.
- Get both Word and PDF copies. File links reveal the saved resume in its folder, with the original resume preserved.
- Keep working in other tabs while tailoring runs, or cancel from the Plan.
- Pricing cards show estimated analyses in Astra, Sol, Luna order, using `~` for approximate counts. Astra uses a Medium example; Sol and Luna use High.

- Use Claude Haiku 5.5, Sonnet 5.5 and Opus 5.5 with Zebby credits. Packs of $20 or more unlock both Astra and Opus, including previous purchases.

The credit service supports a separate tailored-resume task. Generated files remain in the chosen applications database and can be opened again from the Plan.
