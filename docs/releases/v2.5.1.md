# Zebby 2.5.1

- Downloaded models can now use your GPU: Vulkan on Windows x64 and Metal on Apple Silicon. Zebby recommends models based on available memory, and falls back to CPU if GPU startup fails. Your chosen model and thinking level stay the same. Windows ARM64 continues to use CPU inference.
- A redesigned **Credits and devices** view brings recovery, pairing and connected computers together in a two-column layout.
- Credit usage now has an activity grid, daily totals and a compact analysis history. Select a day to see how many analyses ran and how many credits they used.
- **Need help deciding?** explains the analysis options in a compact, two-column guide.
- Switching between Plan, Applications and Settings feels smoother, with reduced-motion support.
- Keyboard shortcuts follow the selected page during transitions, and the titlebar stays in place while editing forms.

Installers are available below for Windows x64, Windows ARM64 and Apple Silicon Mac. Existing users can update from Settings.
