# Zebby 2.9.2

Fixes Apple Silicon GPU detection for downloaded models.

- Recognize the Metal device identifiers used by the bundled local engine. An M1 Max and other Apple Silicon Macs can now select Metal instead of incorrectly using the CPU.
- Recommend models using the detected GPU and available unified memory. A 32 GB Mac with sufficient free memory can recommend Qwen3 14B and 8B.
- Allow more time for the first Metal hardware check and improve diagnostics when a device cannot be recognized.
- Verify native GPU selection and actual layer offload in package checks whenever the test machine reports a GPU.

Your downloaded models can be reused. The existing 30-second idle release, cancellation and manual memory-release controls remain in place.

Includes the compact Boards rows and Edit instructions from 2.9.1.

Includes Windows x64 and ARM64 installers, an Apple Silicon Mac DMG, and a Microsoft Store MSIX bundle for Partner Center submission.
