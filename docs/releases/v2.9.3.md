# Zebby 2.9.3

Fixes incomplete Boards checks on filtered Zoox careers links and similar pages with graphic navigation links.

When the model has identified those links as non-job content and the verified jobs match the page's stated total, Boards completes the check without an unnecessary visual pass through the surrounding careers page. Uncertain links, missing totals, canvas content and ambiguous pagination still require verification.

After updating, choose **Retry** on an existing failed board. Its saved URL and tracking instructions can be reused.

Available for Windows x64, Windows ARM64 and Apple Silicon Macs.
