# Zebby 2.1.2

## A simpler credit wallet

Settings has one Buy credits action, shown when Zebby credits is selected. The purchase dialog shows the four packs without setup notices. Checkout reports a connection error only if the service cannot be reached.

An empty wallet shows Restore credits, Connect this computer and Learn more. A funded wallet shows available credits, usage, percentage remaining and a slim balance bar, followed by the model selector. Reserved credits stay separate from actual usage.

Learn more opens a compact dialog explaining restoration and computer pairing. Recovery-code export, pairing codes, connected computers, recovery-code replacement and recent usage remain available there. Restoration and connection forms retain keyboard submission, cancellation and focus restoration.

## A quieter activity chart

The status legend is removed. Hover or keyboard focus still shows every status count for each applied date. Stacked bars, original dates, totals and keyboard navigation are retained.

No database migration is required. The hosted service still needs to be configured to process payments and online analyses.
