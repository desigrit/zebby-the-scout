# Zebby 2.2.1

## Settings autosave

- Analysis settings save automatically. Provider, model and thinking selections save immediately; server text and API keys save on Enter or when you leave their field or editor.
- Saved keys retain the masked value and compact Change key / Remove key actions. Replacement has Cancel, with no separate Save key or Undo button.
- Cancel and Escape discard a replacement without saving it. Failed key writes keep the existing key and replacement text, and Enter retries.
- First-run setup waits for pending edits and saving to finish before continuing to analysis.

## Updating

Use Zebby's update action or install a direct Windows x64, Windows ARM64 or Apple Silicon download. Existing settings, wallets, models, resumes and databases are preserved. No database migration, environment change or Stripe setup is needed for this update.

macOS builds remain ad-hoc signed rather than Apple notarized. Follow the existing [Mac installation guide](../guide.md) if Gatekeeper blocks the downloaded app.
