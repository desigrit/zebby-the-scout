# Zebby 2.8.1

Boards keeps its results compact and explains website failures more clearly.

- Show the number of listings matching your instructions as **7 listings checked**. Without instructions, the count includes every listing in the saved search.
- Open new matching roles from the **4 new listings** link. Remove View listings, View matches and the extra result filters.
- Read check errors by hovering over, focusing or selecting **Check incomplete**. The explanation stays within the window and closes with Escape.
- Detect unavailable careers pages before AI analysis, retry temporary failures up to twice and preserve the last successful check. This also recognizes error pages returned with HTTP 200.

The Applications and Boards database formats are unchanged.
