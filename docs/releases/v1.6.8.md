# Zebby 1.6.8

## Job descriptions, minus the garbled text

- Fix escaped HTML and character entities appearing in descriptions and Notes, including Greenhouse listings.
- Keep headings, paragraphs, bullets, quotes, and Unicode characters when extracting or pasting job descriptions.
- Display affected saved descriptions and Notes cleanly without rewriting archived copies or clearing existing match scores.
- Preserve complete text when a clipboard's HTML copy is incomplete. Pasting near the field limit keeps existing text after the cursor.
- Limit temporary build artifacts to one day and remove superseded installer artifacts after publishing a release.

This update uses the existing analysis options. The proposed credits and payments integration remains on hold.

Choose the Windows x64 or ARM64 installer, or the Apple Silicon Mac DMG. You can also update from Zebby using **Update**, followed by **Restart to update**.
