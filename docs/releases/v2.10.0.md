# Zebby 2.10.0

Boards automatically tries a thorough check when a page cannot be read completely. It uses your selected vision-capable model to restore filters, open result groups, navigate pages, inspect vacancies and verify the inventory in a fresh pass.

- Stop and resume an incomplete check. Preview listings found so far while keeping your previous successful scan and unread jobs.
- Adjust the time and model-request limits in Settings. Automatic thorough fallback is enabled by default.
- Choose Thorough recheck when editing a board to start a fresh verification.
- Reuse validated analysis and navigation steps, with current filters verified on each check. Older run logs stay in the app folder.
- Read Lyft's Product search from its verified public feed, including filters saved after the URL fragment.

Personal OpenAI and Anthropic keys, Zebby credits and compatible Ollama vision models use the shared reader. Applications and Boards database formats are unchanged.
