# Zebby v1.6.1

- Click anywhere in an application row's empty space to open its details.
- Close the details pane with X. The list fills the space; click the same job or another to reopen it. Keyboard focus returns to the selected job when you close.
- Copy individual ATS keywords and resume themes with the icon immediately before X. Each action copies the current item text and briefly confirms it was copied. Section-wide copy buttons are removed.

Database format and saved data are unchanged.

Use **Update**, then **Restart to update**, or download the Windows x64/ARM64 `.exe` or Apple Silicon `.dmg`.
