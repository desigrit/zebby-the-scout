# Zebby 2.4.1

- Fixed Amazon job imports that returned empty fields after receiving an incomplete compressed page.
- Amazon imports now capture the description, basic qualifications and preferred qualifications, preserving paragraphs and lists.
- Amazon PMT listings separate the role from its team and capture advertised locations.
- Improved HTML extraction to exclude leading scripts, navigation and footer content. Empty responses now show a useful error instead of silently filling nothing.

Installers are available below for Windows x64, Windows ARM64, and Apple Silicon Mac. Existing users can update from Settings.
