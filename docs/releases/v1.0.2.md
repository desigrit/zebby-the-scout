# PM Application Tracker 1.0.2

- A single progress ring replaces match analysis text. Refresh icons sit beside analyzed match results in Applications and Plan.
- Application listing copies now appear in Notes. Existing copies and any previous notes are preserved during the database upgrade, including bullets and paragraph breaks. Original archive fields remain in the database, and a full original backup is saved locally before migration.
- Saving an application edit or status change preserves Notes edited after the form was opened.
- Company labels sit beside role titles. A chevron expands multiple locations into individual labels.
- A slim chart of daily applications over the last 30 days joins the statistics panel. Hover or focus a day to see its date and count; use arrow keys to move between days.
- Plan and Applications use compact action toolbars without repeated page headings.
- Application rows switch to cards when the content pane becomes too narrow, keeping status and row actions in view.

Install 1.0.2 on both computers before opening an upgraded shared database. The upgrade backup includes `before-v8` in its filename inside the app's local Backups folder.

Downloads are direct installers: Windows x64 `.exe`, Windows ARM64 `.exe`, and Apple Silicon macOS `.dmg`.
