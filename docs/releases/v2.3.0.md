# Zebby 2.3.0

## Offers worth celebrating

- Offer received joins the application status list in blue, including filters and the daily activity chart.
- Saving an offer plays three seconds of zebra-striped confetti and little Zebby icons. Controls stay usable throughout.
- Reduce Motion keeps the congratulations message without flying confetti. Opening an existing offer does not replay the celebration.

## Credits and model choices

- The $5 pack is selected by default and marked Suggested start.
- Each pack shows two illustrative analysis counts: GPT-6.1 Sol (High) and GPT-6 Luna (High). The examples use a sample Plan's text sizes plus a separate estimated thinking allowance. Actual usage varies.
- GPT-6 Luna is available through Zebby credits alongside Sol and Astra, including its supported Off thinking option.
- Selected packs use their accent fill and outline without selection labels or a checkmark. The repeated connected-wallet sentence is removed.
- Model downloads use thinner, flat pause/resume and stop icons.

## Updating

Use Zebby's update action or install the direct Windows x64, Windows ARM64 or Apple Silicon download. Your application database, resumes, settings, models and wallet are preserved. No application database migration is needed. Update each computer to use the new offer status.

Self-hosted credits services should apply [the Luna quote migration](https://github.com/desigrit/zebby-the-scout/blob/v2.3.0/credits-service/migrations/20261010_credit_luna.sql) before deploying this service version. It permits Off thinking in quote metadata and retains existing quotes and wallet balances. Luna uses the existing OpenAI service key; Stripe configuration stays the same. See the [service guide](https://github.com/desigrit/zebby-the-scout/blob/v2.3.0/credits-service/README.md).
