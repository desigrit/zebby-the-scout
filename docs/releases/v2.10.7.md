# Zebby 2.10.7

- Tailored resumes now use the uploaded resume's layout. PDF copies keep the original pages and positioning; Word references retain their styles, tables, headers and links.
- Rewrites fit within the reference layout. Wording that cannot fit is kept, with a short note beside the generated files.
- "Create tailored resume" is disabled without a reference, with a prompt to upload one above.

Available for Windows x64, Windows ARM64 and Apple Silicon Mac. The Microsoft Store package is included with this release.
