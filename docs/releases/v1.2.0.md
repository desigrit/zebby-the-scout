# PM Application Tracker v1.2.0

- The full zebra with sunglasses is now the circular app icon, including the sidebar and all installers.
- Coral actions, cyan accents, and cream or charcoal surfaces bring the icon's palette into light and dark appearance.
- Each Core ATS keyword and Core resume theme has an estimated importance percentage based on the job posting. Higher percentages mark bigger CV priorities, independently of resume match strength.
- Recommendations remain editable. Changed or added wording shows Unrated until refreshed. Existing analyses keep their text and show Unrated until a new analysis adds importance ratings.
- New plans reuse the last saved Current CV Overview from the selected database. Existing plans keep their own overview.
- The default window is 300 pixels wider, at 1550 pixels, with a cap to fit smaller screens.

## Database upgrade

Install 1.2.0 or newer on both computers before sharing an upgraded database. The app saves an untouched original copy in its local Backups folder with `before-v9` in the filename before upgrading. Applications, edited Notes, saved job descriptions, resumes, and Plan text are retained. Keep only one computer editing the cloud file at a time.

OpenAI and configured Ollama models retain the full analysis path. Downloadable models stay separate from the database and are reused through updates. SmolLM2 estimates job importance from listing wording and sections in its basic analysis profile. Small models can produce less reliable suggestions and scores; review their output.

## Installers

- Windows x64: `.exe`
- Windows ARM64: `.exe`
- Apple Silicon macOS: `.dmg`

Download the installer directly from the release assets. No ZIP extraction is needed.
