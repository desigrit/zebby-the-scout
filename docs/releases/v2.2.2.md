# Zebby 2.2.2

## Analysis settings

- Quiet rows group provider, model, connection and supported thinking controls, with a compact layout for narrow windows.
- Thinking uses named segments or an On/Off switch. Models without supported thinking controls show no extra control.
- Download sizes appear in separate, muted badges. Model details, terms and local storage expand when needed.
- Downloads use flat pause/resume and stop icons. Stop cancels the transfer and removes partial files, preserving a model that has already completed.
- Installed models have a text Remove action in the local library, with the existing confirmation.
- Provider helpers retain billing details and omit repeated content-sharing sentences.

Analysis settings retain autosave and saved-key recovery. Database, Appearance, Logs and credit wallet controls retain their existing behavior. This update does not change the application database schema.

## Updating

Install the direct Windows x64, Windows ARM64 or Apple Silicon download, or use Zebby's update action. Settings, wallets, completed models, resumes and application databases are preserved. No environment or payment-service setup changes are needed.
