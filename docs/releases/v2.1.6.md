# Zebby 2.1.6

Selecting **Buy credits** now wakes the credits service in the background while you choose a pack. The pricing dialog opens immediately, including when the service is starting or unavailable. This works from Settings, the sidebar and the first analysis setup.

Checkout shares the same startup check if the service is still waking. Only public health requests are retried. Opening or cancelling the pricing dialog does not create a wallet, start checkout or spend credits.

Analysis can still be cancelled during startup. One cancelled request does not interrupt another request waiting for the same service. Startup checks stop after two minutes; there is no periodic keepalive.

No service configuration or database migration is required.
