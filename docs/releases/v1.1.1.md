# PM Application Tracker v1.1.1

## New downloadable CPU models

- **LFM2.5 350M**: 229 MB download.
- **Gemma 3 270M Instruct QAT**: 241 MB download.

Choose **Settings > Analysis > Built-in local, downloadable models**, then select the model. Review the linked terms and choose **Agree and download**. Agreement and model files stay on this computer. Full model terms and notices are included for offline reference.

Both models receive the complete job description, extracted resume text, and full analysis instructions. Small models can miss evidence or produce inconsistent scores and overview suggestions. Only SmolLM2 uses the basic analysis profile. OpenAI and configured Ollama models retain their full analysis path.

Downloads support progress, Pause, Resume, Retry, and Delete with confirmation. Models remain separate from the shared database and survive app updates. This release does not change the database format.

## Installers

- Windows x64: `.exe`
- Windows ARM64: `.exe`
- Apple Silicon: `.dmg`

Download the installer directly from the release assets. No ZIP extraction is needed.
