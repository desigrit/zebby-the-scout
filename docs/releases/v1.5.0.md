# Zebby 1.5.0

## Updates, inside Zebby

- Checks GitHub for a new stable release when the app opens, with a manual check in Settings.
- Shows an Update button in the sidebar and Settings when a compatible release is available.
- Downloads and verifies the installer, then offers Restart to update. Keep using Zebby while it downloads.
- Saves database changes before installation, protects open edits, and preserves your database, settings, API key, and downloaded models.
- Windows installs silently and reopens Zebby. Mac replaces the app bundle and retains the previous app until the new version loads, with recovery on an immediate reopen failure.

Install this release manually once to enable future in-app updates. On Mac, put Zebby in Applications before using them. These remain unsigned builds.

## A tighter desktop shell

- Moves the zebra to the top of the Windows sidebar and directly below Mac window controls.
- Uses larger, 24px navigation icons with short Lottie click animations and a still state for Reduce Motion.
- Uses the standard arrow cursor for clickable controls, with the text cursor in text fields.
- Keeps the collapsed sidebar free of the database footer.

## Zebby artifact folders

- Moves preferences, error logs, working copies, and default databases into a Zebby profile folder.
- Moves downloaded models to the Zebby local data folder, preserving existing downloads and license acceptance.
- Retains cloud database selections and encrypted API keys. Original profile files stay available for recovery.
- Keeps the existing schema 10. No database migration is added by this release.

## Downloads

- Windows x64: `Zebby-1.5.0-win-x64.exe`
- Windows ARM64: `Zebby-1.5.0-win-arm64.exe`
- Apple Silicon Mac: `Zebby-1.5.0-mac-arm64.dmg`

Installers are direct downloads without a ZIP wrapper.

## Verification

Synthetic data checks cover artifact migration, release selection, download verification, recovery paths, and data preservation. Headless UI checks cover Windows and Mac renderer layouts, click motion, reduced motion, update controls, and canceled restarts. Release builds also check real silent NSIS replacement on Windows and real DMG staging, replacement, reopening, and rollback using disposable Mac app fixtures. The desktop app was not opened on the user's PC during development.
