# Zebby 2.3.3

- Simplified the payment confirmation by removing duplicate model and thinking controls. Select these in Settings or before analysis.
- Expanded recovery-code guidance to cover reinstalling Zebby and accessing credits on another device.
- Removed the redundant Cancel action after payment. Use Done, Continue to analysis, or the close button.

The $5 starter pack remains 500 Zebby credits. Existing balances and saved model preferences are preserved.

Update through **Settings > Updates > Check for updates**, or download the Windows x64, Windows ARM64, or Apple Silicon installer below.
