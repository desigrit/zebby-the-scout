# Zebby 2.8.0

Boards can now read more kinds of career pages and show the listings behind each check.

- Use structured Greenhouse, Lever and Ashby feeds when they preserve the saved search filters.
- Read embedded boards, open shadow roots, scrolling lists and multiple results pages before applying tracking instructions.
- Use the selected vision-capable provider to read page screenshots when text and links are insufficient. OpenAI, Anthropic and compatible Ollama models are supported.
- Verify observed job links, filters, totals and page coverage before saving a scan. Interrupted checks preserve the last successful result, and completed paid batches can be reused on retry.
- See how many listings were checked and how many match, then inspect Matches, New or All checked directly in Boards.

Boards continues to use its companion database and the model selected in Settings. Local reading and job comparisons use no credits. Screenshot analysis uses the selected provider and appears as Boards analysis in credit history when paid with Zebby credits.
