# Zebby 2.4.0

- More accurate credit reservations: Zebby counts the complete input and uses a response budget suited to a resume match or full Plan, while keeping your selected model and thinking level. Only actual usage is charged after a successful analysis.
- A $20, $50 or $100 purchase unlocks GPT-6 Astra for your wallet. Existing qualifying purchases count, and you can use any pack for later top-ups.
- Pricing cards show which packs unlock Astra. Selecting a locked Astra in Settings opens those purchase options without changing your current model.
- Clearer balance messages show the credits needed to start and the credits available. Pricing estimates are illustrations, not limits on the number of analyses.

Installers are available below for Windows x64, Windows ARM64, and Apple Silicon Mac. Existing users can update from Settings.
