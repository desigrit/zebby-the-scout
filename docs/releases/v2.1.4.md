# Zebby 2.1.4

Official installers now connect to Zebby's hosted credits service. Choose **Settings > Analysis > Zebby credits** to buy a pack, restore a credit wallet, or connect another computer. There is no Zebby signup or sign-in screen. Model selection follows purchase.

The desktop app waits for the free host to wake before sending credit requests. It allows up to two minutes and retries only public health checks, preserving saved wallet access and avoiding repeated checkout or analysis requests. Analysis can be cancelled during startup.

The service accepts restricted Stripe keys with access to checkout and charge details, while enforcing matching live or test mode. Provider and payment keys stay on the server. The setup guide now covers the live configuration and free hosting behavior.

Hosted checks verified service health, wallet access, an unpaid live Checkout session, and webhook signature handling. The unpaid session was expired without a charge or credit grant. All three OpenAI models completed synthetic structured responses, and all three offered Claude models were listed by the API. Claude analysis requires a funded Anthropic API balance. A completed customer payment and receipt delivery remain separate checks.

No application database migration is required. Existing applications, resumes, plans, settings, downloaded models and local analysis methods are retained.
