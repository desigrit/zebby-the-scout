# Zebby 2.3.2

## Keep working during analysis

- Plan and application analyses continue when you switch pages.
- Open another saved plan or start a new draft while a role is being analyzed. Only the running record is protected from edits and deletion.
- Return to a running Plan to see its progress and elapsed time. Cancel still stops that specific request.
- The elapsed timer appears first, followed by a dot and the current analysis status.

## Fixes

- Restored macOS Command+C, Command+V, Command+X and Command+A, including the API key field. Editable fields also have a native clipboard context menu.
- Fixed Anthropic requests that sent unsupported structured-output constraints. Results are still validated before saving.
- Replaced the generic online analysis error with specific guidance for keys, billing, model access, request formats, timeouts, usage limits and service outages.
- Added safe provider diagnostics with request references, without recording keys, resumes or raw provider responses.
- Database switching waits for active analysis and saves to finish.

Your existing database, settings, resumes and downloaded models are preserved.

## Downloads

- Windows x64: `Zebby-2.3.2-win-x64.exe`
- Windows ARM64: `Zebby-2.3.2-win-arm64.exe`
- Apple Silicon: `Zebby-2.3.2-mac-arm64.dmg`

Existing installations can use **Settings > Updates > Check for updates**.

The Mac build is ad-hoc signed, not Apple-notarized. First-time installs may require the approval steps in the README.
