# Zebby 2.2.0

## Analysis settings

- Provider and model or server controls share an aligned row, with thinking controls below.
- Saved API keys show a mask and last four characters, with compact Change key / Remove key actions. Replacement has Save key / Cancel and retains the old key if saving fails.
- Model lists put newer releases first. Provider and model selections save automatically; server fields save on blur or Enter.
- Thinking level is remembered for each provider and model. Qwen downloads support Off / On; Ollama uses the server's supported controls. Models without thinking support are labeled.
- Selected thinking settings reach the provider and include enough output budget for both reasoning and the final response. Cancellation also reaches Ollama's metadata check. Source content is preserved and models never silently fall back.

## Zebby credits

- Paid analysis offers GPT-6.1 Sol and GPT-6 Astra only. Personal API-key methods retain OpenAI and Anthropic choices.
- Pack estimates use GPT-6.1 Sol at High, with explicit illustrative assumptions in the tooltips.
- Paid quotes bind both model and thinking level. Changing either refreshes the maximum before confirmation. Actual token usage is charged, and unused reservations return to the wallet.
- Model and thinking selection appears once in Settings > Analysis; Credits keeps its usage summary and recovery controls.
- Existing wallets, balances and interrupted paid results remain intact, including results from previously offered models.

## Updating

Use Zebby's update action or install the direct Windows x64, Windows ARM64 or Apple Silicon download. Settings, models, resumes and application databases are preserved. This release does not change the application SQLite schema.

Service operators should run the additive [thinking migration](../../credits-service/migrations/20261010_analysis_thinking.sql) before deploying. The existing Zebby service has been migrated; this update needs no new environment variables or Stripe setup.

macOS builds remain ad-hoc signed rather than Apple notarized. Follow the existing [Mac installation guide](../guide.md) if Gatekeeper blocks the downloaded app.
