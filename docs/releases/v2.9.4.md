# Zebby 2.9.4

Boards rows are more compact and easier to review:

- Current scan progress replaces the previous listings count on the second line.
- A check icon beside new listings marks them reviewed. Hover or focus it to see **Mark as reviewed**. It shows a saving spinner, then gently shrinks and fades away.
- **Custom instructions** uses a light label beside the company name. Read or change the full instructions through Edit board.
- Expanded results show listing rows directly, without the extra heading and description.
- Job links labelled **Apply** use their own card's role title when available. Existing Slack listings recover role names from their saved Workday links.

Review failures keep unread listings available to retry. Reduced-motion preferences skip the exit animation.

Available for Windows x64, Windows ARM64 and Apple Silicon Macs.
