# Zebby 2.0.0

## Payments and analysis choices

The payments integration marks the start of Zebby 2.x. This release includes the features shipped in 1.7.0, with the new major version.

- Choose a local server, downloaded model, OpenAI key, Anthropic key, or Zebby credits when setting up analysis.
- Browse four credit packs, sign in with an email code for paid credits, and choose a model after purchase.
- View available and used credits in Settings and the sidebar. Confirm a maximum before paid analysis.
- Recover a completed paid result without charging again. Failed or cancelled analyses release reserved credits.
- Keep the latest job-description fixes, centered dialogs, and provider billing corrections.

The credits service is prepared for Stripe test mode. Checkout remains unavailable until the hosted service, Stripe, Supabase, and provider credentials are connected. Local models and your own API keys work without a Zebby account.

Choose the Windows x64 or ARM64 installer, or the Apple Silicon Mac DMG. Existing users can use **Update**, then **Restart to update**. Your database, settings, and downloaded models are preserved.
