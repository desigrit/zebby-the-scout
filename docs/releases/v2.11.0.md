# Zebby 2.11.0

ChatGPT plan analysis is now available in public Zebby for Plan, application matching, tailored resumes and Boards.

- Choose **ChatGPT plan** in Settings, connect your account and select an available model and thinking level.
- Review reported tokens, attempt details and saved-result reuse under **Usage**. **Run details** opens the local job folder. The app shows seven days of activity and preserves older files.
- Recover completed analyses without another model request when the source and selections still match. Usage limits pause new requests and preserve successful work.
- Boards includes compact check links and a direct **Manage usage** action when ChatGPT reaches its limit. Public's thorough-check settings remain available.
- Existing public databases, settings, updater and reference resume formatting are preserved.

If you used Zebby - Beta, finish saving and close it, then open the same Applications database in public Zebby. Connect ChatGPT in public Settings and choose your model. Your matching Boards file opens automatically.
