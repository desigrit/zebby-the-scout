# Zebby 2.10.1

More reliable checks for filtered job boards, including Zoom.

- Boards verifies the current screenshot before sending it for analysis.
- Selected checkboxes, filters stored in URL fragments and split result counters are read more reliably.
- Analysis references only links and controls observed on the current page.
- The reader skips invisible menu content and stops repeating steps that add no evidence.
- Existing board links, tracking instructions and successful scan history are preserved.

Update through **Settings > Updates**, or use the Windows x64, Windows ARM64 or Apple Silicon installer below.
