# Meet Zebby

The tracker has a new name, a Graphite wardrobe, and the same zebra in sunglasses.

- Graphite light and dark palettes keep the workspace calm and readable.
- The title bar blends into the sidebar and workspace, with native Windows window controls and Mac traffic lights.
- The title bar shows only Zebby. Click the zebra icon to switch between icons only and icons with labels; the choice is remembered on each computer.
- Zebby keeps your existing database selection, settings, saved API keys, model downloads, and backups. This release does not change the database schema.
- A brief new README introduces Zebby to fellow job seekers, with screenshots using sample data.

## Downloads

Choose the `.exe` for Windows x64 or Windows ARM64, or the `.dmg` for Apple Silicon Mac. Installers download directly without a ZIP wrapper.

On Mac, replace the previous app in Applications with Zebby and remove the old app shortcut. Windows upgrades retain the existing installation identity and update the shortcuts.

These builds are unsigned. Follow the installation notes in the guide if Windows or macOS asks you to approve the app. Quit Zebby and let your cloud drive finish syncing before switching computers.
