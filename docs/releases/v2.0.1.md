# Zebby 2.0.1

## Database safety and local analysis

- Save into the existing SQLite file, preserving its file identity. Saves and schema migrations no longer replace your selected database with a renamed temporary file.
- Keep the last committed database intact when a save is blocked. Pending changes remain available for **Retry save**.
- Refuse saves when the selected file is missing or changed outside Zebby.
- Stream downloaded-model responses and stop workers that time out, disconnect, or stop making progress. Cancelled and failed requests allow a fresh analysis.
- Add detailed local logs for database operations, analysis providers, runtime startup, memory and context checks, token timing, cancellation, transport causes, and update actions. Resume and job-description text are excluded, and stored secrets are redacted.
- Retry transient failures while removing an old Mac app bundle after an update.

Windows x64, Windows ARM64, and Apple Silicon installers are available directly. Existing users can choose **Update**, then **Restart to update**. Your database, settings, and downloaded models are preserved.

The payments features from 2.0.0 remain included. Hosted checkout still requires the service, Stripe, and account setup.
