# Zebby 2.3.9

- Pick from Recents when adding a location in Plan or Applications. Suggestions come from saved jobs, filter as you type, and support keyboard selection.
- More accurate Anthropic and Greenhouse job imports: specific teams are separated from job titles, and multiple locations become individual chips.
- Improved page fallback parsing so workplace policy text is not mistaken for a job location.

Installers are available below for Windows x64, Windows ARM64, and Apple Silicon Mac. Existing users can update from Settings.
