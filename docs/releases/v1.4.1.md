# A little less chrome, a little more clarity

- The zebra and navigation sit higher in the sidebar. Collapsed navigation has no database footer.
- Settings starts directly with Database, Analysis, Appearance, and Logs.
- **Create new database** creates an empty file and switches to it. Your existing database is preserved.
- Errors are logged automatically. Logs has links to open the folder and report an issue on GitHub.
- **Analyze** sits below **Your CV** in Plan, including for plans analyzed previously.
- Plan match scores include a saved **Why** explanation of the resume's strengths and gaps. Older scores can be refreshed to add one.
- Recurring weekly backups are removed. Existing backup files remain, and an original copy is kept before a database format upgrade.

## Updating

Install version 1.4.1 on both computers before sharing a database upgraded by this release. Schema 10 preserves your applications, Notes, resumes, plans, importance ratings, and saved CV overview. Older versions cannot open the upgraded file.

Choose the Windows x64 or ARM64 `.exe`, or the Apple Silicon `.dmg`. Downloads have no ZIP wrapper. These builds are unsigned; see the installation notes in the guide if your computer asks you to approve the app.

Version 1.4.1 is the first installer release for these changes. It also corrects the release checks to wait for provider changes before reading the model dropdown.
