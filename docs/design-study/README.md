# Zebby design study

[Explore the interactive comparison](https://desigrit.github.io/zebby-the-scout/design-study/) · [Read the selection decisions](https://github.com/desigrit/zebby-the-scout#choosing-a-design-direction)

This archive compares nine design directions across Plan, Applications and Settings. It includes sample-data prototypes, screenshots and the original UX review from October 2, 2026.

The later choice combined Ember's palette, Applications and Settings with Rosewood's Plan composition. The existing New Application form and side-by-side keyword/theme sections were retained. The original shortlist and proposed changes remain visible as historical context.

The previews simulate analysis, downloads and saving. They do not connect to model providers or persist job applications. macOS screens are design proposals. The study is not a measured usability improvement or a preview of every current feature.

To view the archive locally, open `index.html` in a browser. Keep the scripts, styles and image folders beside it.
