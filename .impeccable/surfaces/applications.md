# Applications surface

MODE: Operate.

WORLD: A personal search ledger with warm paper, deep forest ink, and terracotta for the main action. Fine rules divide information without putting every detail in a card.

STORY: The user can add several PM applications quickly, then scan dates, match scores, resumes, and hiring status. Daily application volume and totals update as records change. Captured listings remain available offline through Notes.

FIRST VIEWPORT: A dark left sidebar holds Plan, Applications, and Settings beside a compact action toolbar. The add action sits at the right. A slim daily application chart and five useful totals share a ruled panel, followed by search, company and status filters, and the application list. Company labels follow role titles. Match analysis uses one progress ring; analyzed results have a refresh icon. Multiple locations expand through a chevron. Empty accounts show an immediate first-entry action.

SIGNATURE INTERACTION: The add form starts with a job listing link and fills available details from public job data. The user checks each editable field before saving. The status control changes a row in place and updates the statistics. The add and edit form opens within the same work surface so the list remains available for reference.
