# Applications surface

MODE: Operate.

WORLD: A personal search ledger with warm paper, deep forest ink, and terracotta for the main action. Fine rules divide information without putting every detail in a card.

STORY: The user can add several PM applications quickly, then scan dates, match scores, resumes, and hiring status. The totals update as records change.

FIRST VIEWPORT: A compact dark identity strip sits above a large serif Applications heading. The add action stays beside the title on desktop and immediately below it on mobile. A ruled band shows five useful totals, followed by search, status filtering, and the application list. Empty accounts show an immediate first-entry action.

SIGNATURE INTERACTION: The add form starts with a job listing link and fills available details from public job data. The user checks each editable field before saving. The status control changes a row in place and updates the statistics. The add and edit form opens within the same work surface so the list remains available for reference.
